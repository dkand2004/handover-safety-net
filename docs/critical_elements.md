# Safety-critical elements (draft)

Items a handover summary must not lose. Drawn from general knowledge of Queensland ieMR-style
patient summaries. **To be verified against official clinical sources before publishing.**

| Element | Example in a synthetic note | Why it matters |
|---|---|---|
| Allergies / adverse reactions | "Penicillin: anaphylaxis" | Wrong drug can be fatal |
| Resuscitation status (ARP) | "Not for CPR" | Wrong response in a deterioration |
| Falls risk | "High falls risk, vision impaired" | Prevents in-hospital falls |
| Pressure injury risk | "High risk, 2-hourly turns" | Prevents pressure injuries |
| Medication: drug, dose, units, route, last given | "Paracetamol 1 g oral, last given 06:00" | Dosage errors and double-dosing; checked as an **exact match** |
| Anticoagulants | "On apixaban, last dose 48 h ago" | Bleeding or surgery risk |
| Deterioration trigger (Q-ADDS) | "Q-ADDS 4 (orange), escalated" | Missed deterioration |
| Isolation precautions | "Contact precautions" | Infection spread |
| Laterality (eye/limb surgery) | "RIGHT eye" | Wrong-site surgery |
| Pending critical tasks | "Repeat BP in 30 min" | Lost follow-up |
